# EndoControl — как запустить

## На своём Mac (попробовать)

1. Установите Node.js версии 22 или новее: https://nodejs.org (кнопка «LTS»), установщик для macOS.
2. Откройте программу «Терминал» и выполните по очереди:

```bash
cd ~/Desktop/"контроль диабета"/endocontrol
node scripts/demo.js
node server.js
```

3. Откройте в браузере http://localhost:1337

Демо-входы:
- пациент: `demo@endocontrol.app`, пароль `demo1234`
- врач: `doctor@endocontrol.app`, пароль `demo1234`

Остановить сервер — `Ctrl + C` в Терминале.

## ИИ-аналитик

Вкладка «ИИ-аналитик» разбирает данные за 14 дней и отвечает на вопросы. Без ключа она показывает автоматический разбор по правилам. Чтобы включить ИИ (Claude от Anthropic):

1. Получите API-ключ на https://console.anthropic.com
2. Перед запуском сервера выполните в той же папке:

```bash
npm install
ANTHROPIC_API_KEY=ваш_ключ node server.js
```

Для ответа вопрос и сводка данных за 14 дней отправляются в Anthropic: укажите это в политике конфиденциальности. Аналитик не рассчитывает дозы инсулина.

## Голосовой помощник и Школа диабета

- Кнопка 🎙️ в правом нижнем углу открывает голосового помощника. Спрашивать можно голосом или текстом, ответы он читает вслух. Голосовой ввод работает в Chrome, Edge и Safari; речь распознаёт браузер (в Chrome — через Google). Для голоса страница должна открываться по `https://` или с `localhost`.
- С ключом `ANTHROPIC_API_KEY` отвечает Claude, без ключа помощник отвечает по урокам Школы диабета.
- Вкладка «Школа» — 10 коротких уроков с мини-тестами. Пройденные уроки запоминаются в этом браузере.

## Чтобы подключить настоящий датчик

- **LibreLinkUp и Dexcom Share** работают и с вашего Mac: сервер сам забирает сахар из облака производителя каждые 5 минут, пока он запущен.
- **xDrip+, Juggluco и другие приложения на телефоне** отправляют данные на сервер через интернет. Для этого сервер должен быть доступен по адресу `https://…`, то есть размещён на хостинге с доменом (см. README.md, раздел Deploy). Подойдёт любой VPS, Railway, Render, Fly.io.

## Языки

Язык выбирается в правом верхнем углу: 14 языков, включая русский, казахский, английский, китайский, испанский и арабский.

## Важно

Это рабочая основа, а не сертифицированное медицинское изделие. Перед запуском для пациентов нужны юридическая проверка (персональные медицинские данные), политика конфиденциальности, резервные копии и проверка безопасности.
